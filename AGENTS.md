# OpenMirror development

- Local AirPlay screen mirroring for iPhone → Fire TV; no cloud, subscriptions or document uploads.
- Never equate mDNS registration/discovery, TCP connection or build success with working mirroring.
- Keep GPL and third-party notices. Track changes from uxplay-android explicitly.
- Run source-built OpenSSL before APK builds. Never commit keys, local.properties, logs or toolchains.
- Verify on target hardware before claiming compatibility. Record iOS/model/Fire OS and actual observations.
- Use README.md, docs/TESTING.md and docs/VALIDATION.md for build and evidence.
